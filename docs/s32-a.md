## 既定（どれも仮）

- 新しい問い・知らせは増やしていない。言語モデルの呼び出しも無い。中身の文は Tally に書かない（数と種類の名前だけ: `s32a.fix.<what>`・`s32a.fix.undo`・`s32a.prompt.ledger`・`s32a.prompt.base`・`s32a.prompt.quiz`・`s32a.term.open`・`s32a.know.open`・`s32a.glossary.open` ほか画面を開いた数）。
- 端末に覚えるもの（UserDefaults）: `s32a.fixes`（項目の id → 直し）。
- 見出しの言い方: 会議（会議と予定・会議・予定〔中点つき〕・今日の会議）・メール（Outlook のメール）・チケット（チケットの一覧）・ケース（テストケース・ケースの一覧）・言葉（用語集。「用語」だけは見出しにしない）・体制（体制図・体制表）・仕組み（仕組みのつながり）・番号の決まり（番号のきまり・番号の付け方）・自分の役割・答え（質問への答え）。会議・メール・チケット・ケース・言葉・体制・仕組み・答えは、かっこで始まる行か見出しだけの行のときだけ見出し。
- （HH:MM 名前）として外すもの: 時刻（全角・「〜」の幅も）で始まるかっこ。「まで」「から」「頃」の入ったもの・ありえない時刻・時刻の無いもの・文がかっこだけのものは外さない。時刻だけのかっこも外す（人は無し）。名前だけのかっこ（時刻の無いもの）は、ほかのかっこと見分けられないので外さない。

## ほかの担当との約束

- 母艦（s32m・M1）: K2 の `quiz` に `prompt`（職場の Claude への頼み方の文）があれば、アプリはそれをそのままコピーする（無ければ `questions` から組み立てる・質問が 0 なら押せない）。答えは【答え】に 1 行 `q印｜答え`（q印は `quiz.questions[].id`）。
- 母艦（s32m・M1）: `Import-WorkDigest.py` は K32-1 の鍵 9 つに加えて **`answers`**（【答え】・AI からの質問の答え。1 行が「質問の番号｜答え」）も読んでほしい。アプリの頼み方は【答え】の 1 行を `・q1｜…` の形で頼んでいる（番号は K2 の `quiz.questions[].id`）。行は `sections` に生のまま（出どころの番号・（HH:MM 名前）も付いたまま）入っている。
- 母艦（s32m・M1）・家の PC（s32p）: `work_fix` の `value` は、案件が違うときは選んだ案件の id（K2 の `projects[].id`）、人が違うときは選んだ人の id（K2 の `people[].id`）、それ以外と「分からない」は null。戻しは送らない。家の PC の `s27pwork.parse_feedback` が `work_fix` を受けて `inbox/app_feedback.jsonl` に 1 行足す形になっていないと、送り箱で弾かれる（5 回で捨てる）。
- 母艦（s32n・M2）: K2 の新しい鍵の数は数・文字・配列（その数）のどれでも読む（`days`・`items`）。`threads[].items` が id の並びなら、押すと項目の一覧を出す。`scorecard.rows[]` は `key`（見せない）・`label`・`detail`（ラベルの下に小さく）・`now`・`prev`（数か文字「34/196」。`prev` が null なら差は出さない）・`unit`。`guide` は `{written_at, by, stale}`（`written_at` は時差つきの ISO・日だけでも読む。`by` が "rules" なら「規則の版」、"subscription" なら「定額の枠で作り直し」、`stale` なら「古い」）。`systems.stuck` は箱の id。
