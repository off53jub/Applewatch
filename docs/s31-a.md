## 既定

- 新しい問い・知らせは増やしていない。言語モデルの呼び出しも無い。中身の文は Tally に書かない（数と種類の名前だけ: `s31a.voice.open`・`s31a.pair.open`・`s31a.conv.open`・`s31a.play`・`s31a.read`・`s31a.read.none`・`s31a.read.bad`・`s31a.read.fail`）。
- 端末に覚えるもの: UserDefaults `s31a.offered`（features の links）。写しは `Application Support/S31A/`（日は `day-YYYY-MM-DD.json`、人は名前をそのまま使わず 16 進の名前）。features から links が消えたら写しを全部消す。
- 結びは候補として扱い、記録・人の帳は書き換えない。仕事の結び（`work:true`）の文字は仕事タブの伏せる切り替えに従う（人のページ・日の画面でも）。

## ほかの担当との約束

- 家の PC（s31p）: `GET /links?day=YYYY-MM-DD`・`GET /links?person=<名前>`（アプリは人のページの名前で聞く。id では聞いていない）・オーナーの Bearer・無いときは `{"available":false}`・features の `links`。答えは `state/s31_links_for_app.json` を絞った K31-1 の形（`links`・`people`）。
- 母艦（s31m）: K2 の項目の `voice` は 2 件まで（3 件目からは読まない）。`start` は時差つきの ISO（無ければ端末の時刻として読む）。link の `text.quote` が無い行・`voice` が無い行は読めないので飛ばす。
