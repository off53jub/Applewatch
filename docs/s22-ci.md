## 動き方

- `screens-grid` は macOS で動き、必須の検査や既存の `screens` ジョブと並べて走ります。実測（1 回目）は約 31 分（`screens` は約 67 分）。
- 既存の `screens`（ScreenTour）には `-skip-testing:LifeLogUITests/ScreenMatrix` を付けて、二重に走らないようにしました。
- `changes` ジョブの判定は、`ui` が false（時計だけ・テストだけ・pc/・docs だけ）なら `screens-grid` も飛ばします。報告用の script（grid・contrast・words）だけを変えたときは build・test を飛ばします。
- 作り置き（キャッシュ）のキーは `spm-grid-`・`cc-grid-`（ほかのジョブと分けてあります）。
- 文字最大は、起動の引数と、シミュレーターの設定（`simctl ui content_size`）の両方で入れます。

## いまの数（2026-11-22 の PR #95 の実行）

- 見1: 撮れた画面 60 枚（20 画面 × 3 通り）・開けなかった 0。
- 見2: はみ出し 0・省略の印 0・つぶれ 0。**ただし 1・2 回目とも、文字最大の写真が暗い画面と同じ大きさだった**（文字が大きくなっていない）。1 回目は起動の引数の名前が間違っていたため、2 回目は simctl の設定が効かなかったためです（仮説: 画面の起動時に設定が反映されない）。3 回目で引数の名前を正しい値（`UICTContentSizeCategoryAccessibilityXXXL`）に直しました。数は、文字が実際に大きくなった写真で数えた値だけを信じてください。

## 気づいたこと（アプリの担当へ）

- 暗い画面で「面談の 1 枚」の本文が真っ白（明るい画面と同じ）。暗い画面で白い面が出ている（写真 暗-15）。
- 見3 の 8 組は、明るい画面の差し色・よかった・注意の文字色を少し濃くすれば 4.5 を超えます（LLTheme.swift の light の値）。
- 見4 の 125 件は、画面の言葉の一覧（docs/s20-design.md の 5 章）の「分かる言葉」へ言い換える候補です。数えているのは Text・Label・Button・navigationTitle などの最初の文字列だけで、変数を通って出る文字は含みません（仮説: 実際はもっと多い）。

## 限界（仮説を含む）

- SwiftUI が自動で「…」に縮めた文字は、読める文字が変わらないので、UI テストでは数えられません。数えるのは、枠が画面の横にはみ出す・幅がほぼ無い・文字そのものが「…」で終わる、の 3 つだけです。
- 画面の写真は、CI のテスト用の見本の記録だけです（実データは無い）。
