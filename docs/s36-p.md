# s36 家の PC（担当 p・2026-11-28）

取り決め K36-1〜4 の家の PC の分。名前と形は取り決めのまま。どれも**家の PC が新しい版に上がるまでは動かない**（アプリは features に無ければ前の動き）。

## K36-1 GET /s36（`pc/s36pwork.py`）

- オーナーの Bearer。母艦の `state/s36_for_app.json` をそのまま返す（作るのは母艦の担当）。
- 無い・壊れ・大きすぎ（12MB）・止めてある・母艦が無い → `{"available": false, "reason": …}`（GET /s34 と同じ「まだ」の返事）。
- features `"s36"`（ファイルがあって止めていないとき）。止める: `state/s27_work_config.json` の `"s36p": {"s36": false}`。

## K36-2 POST /work/photo の kind と 30 枚（`pc/s35pwork.py`）

- 体に省ける `"kind": "digest"|"cases"|"bugs"`（省けば digest・ほかは 400）。`count` は 1〜30（細1。前は 12）。
- `meta.json` に `kind` を残す（`{"id","day","kind","count","received","at"}`）。同じ id で kind が変われば数え直す。
- cases/bugs でも、そろったら同じ起こし方（`Run-WorkNow.py --kick`）。
- features `"workphoto30"`（`workphoto` と同じ決まり）。

## K36-3 POST /s36/stop（`pc/s36pwork.py`）

- オーナーの Bearer。体 `{"id": 1〜80 字, "choice": "stop"|"keep"}` を検め（改行などの制御文字は断る）、
  `<母艦>/inbox/s36_stop/<時刻>-<id の安全な形>.json` に `{"id","choice","at"}` を置くだけ。返事 `{"ok": true}`。
- 安全な形は英数字・`_`・`-` だけ（ほかは `_`。何も残らなければ `x`）。同じ名前があれば `-2` を足す（上書きしない）。一時ファイルから入れ替える。
- 止めてある（`"s36p": {"stop": false}`）・母艦が無い → 書かずに `{"ok": false, "reason": …}`。features `"s36stop"`。
- 記録には choice と件数だけ（id は書かない）。止めるのは母艦の担当（選ばれた stop だけ）。

## K36-4 /ask-mothership の scope（`pc/askmother.py`）

- 体に省ける `"scope": "all"|"work"`（省けば今のまま・ほかは 400）。features `"askwork"`（`askmother` と同じ決まり）。
- work のときは、仕事の材料を先に引いて、いちばん前の組で Claude に渡す: 台帳 `state/s25l_work_ledger.json`（`merged_into` は外す）・
  K2 `state/work_for_app.json`（今日の一覧・案件の項目・決まったこと）・`state/s32_work_items.json`（時刻とだれ）・
  `state/s36_for_app.json` の cases・bugs。選び方は規則（質問と探し方の言葉の重なり・「待ち」「決まった」「不具合」「テスト」などの言い方）・30 件まで・0 円。
- 返事の形は今のまま。仕事の材料の 1 件には省ける `who`（だれ。確かなときだけ）・`via`（`summary`＝まとめ・`voice`＝声・`table`＝表の写真・`other`）・`ref`（W-<数>）が付く。
  `searched` に省ける `scope`・`work`。推定の人（K2 の `who_guess`）は Claude には渡すが、`who` にはしない。
- 「頼まれごと帳（議事録から）」は声とみなす（仮）。
- Claude の purpose は `askmother.s36-work.plan`・`askmother.s36-work.answer`（`askmother` の前方一致の上限の中）。さらに 1 日 20 回（仮）まで。超えたら 409 `{"purpose_off": "daily_cap"}`。
- 記録には数だけ（質問・答え・材料の中身は書かない）。
