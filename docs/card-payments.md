# カードの支払いを取り込む（2026-11-09）

「行ったお店」の答え合わせに使う支払いの記録は、次の3つから集めます。同じ支払いは1件にまとめます。

| 入口 | 何が分かる | 届くまで | 入れ方 |
|---|---|---|---|
| PayPay の明細（CSV） | PayPay で払ったお店・金額 | 月に1回、手で | 「行ったお店」→「明細（CSV）を読み込む」 |
| カードの利用速報メール | PayPay カードで払った先・日時（分まで）・金額 | 15〜30分 | 下の「1. 利用速報メール」 |
| ウォレットでかざした記録 | かざした時刻（秒まで）。カードによっては店・金額も | すぐ | 下の「2. ウォレットでかざしたとき」 |

残すのは時刻・金額・払った先・カードの名前だけです。カードの番号やメールの本文は残しません。

## 1. 利用速報メール（Google の Apps Script）

```
Gmail（利用速報）→ Apps Script（自分の Google アカウントの中で15分ごと）
  → ドライブ「LifeLog/カード利用/card-mail.json」
  → 家の LifeLog PC（Google ドライブ for desktop の G: などから読む。GET /card）
  → iPhone（30分に1回まで読み直す。card-mail.json に写しを置く）
```

メールを外へ転送しません。PC やアプリに Gmail の鍵も置きません。

### 入れ方（一度だけ）

1. パソコンのブラウザで https://script.google.com を開き、「新しいプロジェクト」を作る。名前は「LifeLog カード利用」など。
2. 最初からある中身を消して、このリポジトリの `google/CardMail.gs` を全部貼り付け、保存する。
3. 上の関数の選び口で `setup` を選び、「実行」を押す。
   - 「承認が必要です」→ 自分のアカウントを選ぶ →「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」。
   - 自分で作ったスクリプトなので、この表示が出ます。求められるのは「Gmail を読む」「ドライブのファイルを作る」と「時間で動かす」です。
   - 過去 400 日分の利用速報を読み、15分ごとに動くよう登録します。
4. 関数の選び口で `checkFormat` を選んで実行し、下の「実行ログ」を見る。
   - `送り主: …paypay-card.co.jp（受け付ける） / {"time":…,"amount":…,"shop":…}` と出れば読めています。
   - `（受け付けない）` と出たら、利用速報の送り主のドメインが想定と違います。`CardMail.gs` の `SENDERS` に、そのドメインを足してください（件名をまねた詐欺メールを読まないため、送り主で絞っています）。
5. 少しすると、ドライブの「LifeLog」フォルダに「カード利用」フォルダと `card-mail.json` ができます。

### メールの形

件名は「PayPayカード ゴールド（Visa）利用速報」。本文は上から「払った先」「2026年10月20日 7:10」「35,000円」の順に並び、項目名はありません。
`parse_` は、日時の行の1つ前の行を払った先、日時のあとの「〜円」を金額、件名の「利用速報」より前をカードの名前にします。
払った先が「VISA国内加盟店」のような大まかな名前のときは、お店の名前には使いません（その時刻にかざした記録に名前があれば、そちらを使います）。

## 2. ウォレットでかざしたとき（ショートカット）

iPhone の「ショートカット」→「オートメーション」→「＋」→「取引」。

1. 「カード」で、記録したいカードを選ぶ（PayPay カード・PASMO など）。
2. 「すぐに実行」を選ぶ。
3. 動作に「LifeLog」の「支払いを記録」を入れる。
4. 「店」「金額」「カード」に、変数の「ショートカットの入力」を入れ、それぞれ「販売者」「金額」「カードまたはパス」を選ぶ。

かざすたびに、時刻と、届いた分の店・金額・カードが iPhone の中（`card-taps.jsonl`）に残ります。
日本のカードでは店や金額が空で届くことがあります。空でも時刻は残り、15分以内の同じ金額（金額が空なら金額は問わない）の利用速報メールと1件にまとめます（時刻はかざした方、名前は分かる方）。

## 同じ支払いのまとめ方（`PaymentMerge.combine`）

- PayPay の支払いに PayPay カードを使ったとき: 利用速報の払った先が「PayPay」になる。10分以内に同じ金額の PayPay の明細があれば、明細のほう（お店の名前がある）を残す。
- かざした記録と利用速報: 上のとおり。
- 名前の無い支払い・大まかな名前の支払いは、立ち寄りの名前と推測の答え合わせには使わない（「払ったお店」の一覧には「（店名なし）」で出る）。

## ファイル

- iPhone: `payments.json`（PayPay の明細。前と同じ）・`card-mail.json`（利用速報の写し。家の PC から読むたびに作り直す）・`card-taps.jsonl`（かざした記録。足すだけ）。どれも端末ごと・同期しない。
- PC: 読むだけ。場所を変えるときは `config.json` の `"card_mail_file"`。
