# 行ったお店（2026-11-08）

位置・近くのお店・その時間の会話から、どのお店にいたかを推測して「12:10〜12:45 たぶん〇〇」と残す。
本人が決めるまでは推測（たぶん）のまま。コードは `LifeLog/ShopVisits.swift`（決まりと帳）と `LifeLog/ShopVisitViews.swift`（画面）。

## 使い方

1. 「記録」→ 上の「場所」→「行ったお店」を開き（2026-11-11 までは「人と場所」の中）、下の「行ったお店を推測する」をオンにする。
2. 設定アプリ →「LifeLog」→「位置情報」を「常に」にする。「正確な位置情報」もオンにすると当たりやすい。
3. お店に3分以上いて出ると、一覧に出る。押すと「合っている」・ほかの候補・「名前を入れる」・「お店ではない」で決められる。

## しくみ

- **立ち寄り**: `CLLocationManager.startMonitoringVisits()`（オンのあいだだけ。電池は少し多く使う）。いる途中（出た時刻が分からない）の立ち寄りは、出た知らせが来たら同じものに出た時刻を入れる。
  3分未満の立ち寄りと、登録した場所（自宅・会社など。半径＋位置の精度、精度は100mまで）の中の立ち寄りは残さない。
- **候補（Apple が先）**: `MKLocalPointsOfInterestRequest`。半径は位置の精度を 40〜150m に収めたもの。飲食・カフェ・パン・酒・食料品・お店・薬局・飲み屋・ジム・美容・スパ・コインランドリー・映画館。近い順に8つまで。
- **Google はいるときだけ**: Apple で見つからない、または1位と2位の点数の差が 0.25 より小さいときで、本人がキーを入れていて、回数の上限の中で、その立ち寄りでまだ聞いていないときだけ。
  `POST https://places.googleapis.com/v1/places:searchNearby`（Places API (New) の Nearby Search。距離の順・日本語・10件まで）。駅・公園・学校などは候補に入れない。Apple と同じ店は足さない。
- **点数**: 距離が元（0〜1）。会話に名前が出たら +3、名前の一部（「〇〇店」を除いた形・区切りごとの部分）なら +2。本人が前に決めた近く（80m）のお店は +1。
  種類の言葉（「ご注文」「店内」「テイクアウト」→ 飲食・カフェ、「ポイントカード」「袋」「レシート」「お会計」→ お店、「処方箋」→ 薬局 など）は1つ +0.25（0.75 まで）。
  名前は全角・半角、ひらがな・カタカナ、大文字・小文字、空白と記号をそろえて比べる。
- **会話は iPhone の中だけ**: 立ち寄りの時間（前後2分）の行を読む。テレビ・動画の行は除く。クラウドの言語モデルは使わない。
  仕事の時間・職場（記録の「職場の会話」と同じ判断）の立ち寄りは、会話を読まない。
- **いつ推測するか**: 出た知らせが来たとき。アプリを開いたとき、24時間以内のまだ決めていない立ち寄りのうち、調べられなかったもの（通信できなかったなど）と、会話の行の数が変わったもの（あとから文字になった）だけ推測し直す。出た知らせが来ないまま6時間たった立ち寄りは、着いてから1時間の会話で推測する。

## 保存

- 新しいファイル `shop-visits.json`（端末ごと・同期しない）。小さいので長く残す。読めないファイルは上書きせず `shop-visits-unreadable.json` に置く。読む前に保存しない。
- **Google の決まり**: Google の候補の place id は長く残してよいが、名前と位置は30日まで。読み込むときと保存するときに、30日を過ぎた Google の候補の名前と位置を消す。本人が決めた候補と、本人が決めた名前（本人のもの）は消さない。
- 回数（今日・今月）は UserDefaults の `shopGoogleCalls`、上限は `shopGoogleDayCap`（20）・`shopGoogleMonthCap`（300）、オン・オフは `shopVisitsOn`。

## Google のキーと料金

- キーは「行ったお店」の画面の下で入れる。この iPhone のキーチェーンにだけ置く（コード・記録・UserDefaults・ログには書かない）。
- キーの作り方: Google Cloud のコンソールでプロジェクトを作り、「Places API (New)」を有効にして、API キーを作る。キーの制限で「Places API (New)」だけに絞り、できれば iOS アプリ（バンドル ID `com.off53jub.lifelog`）にも絞る。請求先アカウントの設定が要る。
- iOS アプリで絞れるのは 2026-11-08 の版から（Google に聞くとき `X-Ios-Bundle-Identifier` を付けるようにした）。それより前の版で絞ると、Google に断られて候補が出ない。
- 料金: Nearby Search には毎月の無料の分があり、それを超えると1回ごとに料金がかかる（値段と無料の分は Google の料金表で確かめる）。アプリは1日・1か月の上限（初めは20回・300回）を超えたら聞かず、Apple の答えだけで推測する。念のため Google Cloud 側でも1日の上限（割り当て）と予算の知らせを付けておくとよい。

## 送るもの

- Apple: 立ち寄った位置（近くのお店を探すため）。
- Google: キーを入れていて、Apple の答えがはっきりしないときだけ、立ち寄った位置と半径。
- 会話はどこにも送らない。
