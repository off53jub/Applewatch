# 前の版に戻す手順（2026-11-23。s23 の 届9）

新しい版がおかしいときに、前の版へ戻すための 1 枚です。ここに書いたことは、リポジトリのコードと CI の設定から読める事実だけです。実機で戻してみた記録は無いので、戻したあとは「実機で未確認」の扱いにしてください。

先に知っておくこと:

- アプリの「版」は、CI の実行の番号（`CURRENT_PROJECT_VERSION` = `github.run_number`）です。TestFlight にも GitHub のリリースにも同じ番号が付きます。
- 戻すと、あとの版で入った機能・直しも消えます。記録のファイルは消えませんが、新しい版でしか読めない形の控えがあれば、戻した版では読めないかもしれません（仮説。確かめていません）。

## 1. iPhone のアプリ（時計のアプリも一緒）

時計のアプリ（LifeLogWatch）は iPhone のアプリの中に入っています（`.github/workflows/testflight.yml` が「Watch アプリは IPA に入っている」を確かめています）。だから iPhone のアプリを前の版にすれば、時計のアプリも iPhone から前の版が渡されます。時計だけを別に戻す道具はありません。

### A. TestFlight から（いちばん手軽）

1. iPhone の TestFlight アプリで LifeLog を開く。
2. 「以前のビルド」（Previous Builds）から、戻したい番号を選んで「インストール」。
   - 出るのは、内部テストのグループに渡したビルドだけです。main に入ったビルドだけがグループに渡されます（`.github/scripts/asc.py` の `give_to_testers`）。PR のビルドは TestFlight の一覧に出ても、テスターには渡りません。
   - TestFlight のビルドは、Apple の決まりで一定の日数がたつと使えなくなります。古い番号が選べないときは B へ。
3. 入れたあと、時計の LifeLog を一度開く（アプリを新しくしたあとは、時計の録音が届かないことがあります。`WatchRescue.swift` の知らせの文のとおり）。

### B. GitHub のリリースから（署名なしの IPA）

1. GitHub の `off53jub/Applewatch` →「Releases」から、戻したい版（`v日付-番号`）を選ぶ。main に入るたびに作られます。
2. `LifeLog-unsigned.ipa` を取って、Windows の Sideloadly などで自分の Apple ID で署名して入れる（`README.md` の手順どおり）。うまく入らないときは `LifeLog-unsigned-no-widgets.ipa`（拡張機能を抜いた版）。
3. 無料の署名は期限が短いので、期限の前に入れ直す必要があります（アプリが期限を知らせます）。

どちらも、新しい版の上に入れる（上書き）形です。うまくいかなければ、いったん消してから入れ直すと記録の控えも消える場合があるので、先に同期のフォルダ（Google ドライブ）に記録が上がっていることを確かめてください。

## 2. 家の PC（LifeLog PC）

家の PC は、GitHub のリリース `pc-v<版>-<作った回の番号>`（例 `pc-v10-123`）を自分で取ってきて入れ替えます（`pc/updater.py`）。起動して 10 分後と、そのあと 1 時間ごとに確かめます。

### すぐ戻す（入れ替えの直後）

入れ替えのとき、古いフォルダが「<フォルダの名前> 前の版」として 1 つだけ残ります（`pc/README.txt`）。

1. LifeLog PC を止める。
2. 今のフォルダの名前を変える（例: 末尾に「 だめだった版」）。
3. 「前の版」のフォルダを、もとの名前に戻す。
4. 起動する（タスク スケジューラの `Lifelog-HomePC-Autostart`）。
5. **自動の更新を止める**: 止めないと、1 時間以内にまた新しい版を取ってきて入れ替えます（更新は「いま入っている作った回の番号より新しい `pc-v*` のうち最新のもの」を選ぶ決まりのため）。`config.json` に `"auto_update": false` を足すか、`LifeLogPC.exe --no-auto-update` で起動します。

### 前の前の版へ戻す（「前の版」が使えないとき）

1. GitHub の Releases から、戻したい `pc-v10-N` を探す（「Pre-release」の印が付いています）。
2. `LifeLogPC.zip` と `LifeLogPC.zip.sha256` を取り、SHA-256 が合うことを確かめる。
3. LifeLog PC を止めて、今のフォルダを別の名前に変え、zip を展開した `LifeLogPC` フォルダをもとの場所に置いて起動する。
4. 上の 5 のとおり、自動の更新を止める。
5. 直したあと新しい版へ進めるときは、`auto_update` を戻す（または「ダッシュボード」の「更新を確かめる」）。

家の PC の作業は、動いているものを止めることになります。録音の文字起こしの最中でないか確かめてからにしてください。

## 3. 戻したあとに確かめること

- iPhone: TestFlight アプリの LifeLog の欄に出る番号が、戻した番号か。
- 時計: 時計の LifeLog を一度開いて、録音の丸が点くか。
- 家の PC: ダッシュボードの「版と作った回の番号」が戻した番号か。
- 戻した理由は、あとで直すときのために PR かメモに残す。
